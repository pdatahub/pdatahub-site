# pdatahub-site

Landing page for [pdatahub](https://github.com/pdatahub/pdatahub).

Hosted at: https://pdatahub.github.io/pdatahub-site

## Local preview

Open `index.html` in a browser. No build step.

## Deploy

GitHub Pages auto-publishes from `main` branch. Settings → Pages → Source: `main` / root.

## Structure

- `index.html` — single-page landing (HTML + inline CSS, no JS, no dependencies)
- `404.html` — placeholder, redirects to root
